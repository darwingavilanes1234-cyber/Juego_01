\## Objetivo del sistema



Desarrollar un sistema funcional del juego Piedra, Papel y Tijera, aplicando conceptos de lógica de programación, estructuras condicionales, estructuras repetitivas, diseño funcional, arquitectura de software y uso de GitHub como herramienta de control de versiones.



\## Descripción del proyecto



El proyecto consiste en un juego interactivo de Piedra, Papel y Tijera, donde el usuario selecciona una opción y el sistema genera automáticamente una jugada aleatoria. Luego, el programa compara ambas jugadas y muestra el resultado de la ronda.



El sistema permite aplicar reglas básicas del juego:



\- Piedra gana a tijera.

\- Tijera gana a papel.

\- Papel gana a piedra.

\- Si ambas jugadas son iguales, el resultado es empate.



\## Funcionalidades



\- Iniciar el juego.

\- Seleccionar piedra, papel o tijera.

\- Generar una jugada aleatoria para la computadora.

\- Comparar las jugadas.

\- Mostrar si el usuario gana, pierde o empata.

\- Llevar marcador de la partida.

\- Reiniciar el juego.

\- Salir del sistema.
